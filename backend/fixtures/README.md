These are synthetic historical calls for a fictional clinic fixture agent. That
agent handles booking, cancellation, billing with name/reference verification,
and simulated human escalation. Each fixture includes its intended expectations
and planted failure category for offline judge evaluation.

They are not calls from the selected agent. The application does not expose a
fixture-loading endpoint or attach these findings to user agents. To review a
call in the UI, analyze a completed test call or import a transcript explicitly
confirmed to belong to that agent.
